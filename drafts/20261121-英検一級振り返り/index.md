# はじめに

2026年度第2回の英検1級を受験しました。

結果は、一次試験はなんとか合格、二次試験は合格基準まであと6点届かず不合格という、惜しいものでした。

この記事では、一次試験と二次試験それぞれの体験や当日の注意点、そして成績の振り返りをまとめます。

## 一次試験体験記

一次試験は2026年10月4日に受験しました。

試験対策は単語帳を学習したくらいでした。今回が初めての受験なので、合格できればもちろんうれしいものの、まずは試験の雰囲気や進め方をつかめれば十分、という気持ちで臨みました。

### 当日の流れ

初受験だったこともあり、当日の流れについて学びがありました。

会場は筑波大学春日キャンパスでした。

試験開始は14時でしたが、13時30分から説明が始まり、その時点でスマートフォンの電源を切る必要があります。13時50分までは読書ができたので、暇つぶし用に本を持参したのは正解でした。

試験中の時間配分では、**ライティングを先に、リーディングを後に**解く戦略を取りました。時間が足りなくなるとすればライティングのほうで、リーディングは最悪あてずっぽうでも埋められる、と考えたからです。順番が逆だったら、おそらくライティングの時間が足りずに不合格だったと思います。

さらに、リーディングを手早く終えて（見切りをつけて）、残りの10分ほどをリスニング問題の先読みに充てられたのもよかった点です。

### 試験直後の感想

試験直後の率直な感想は、次のとおりです。

- **リーディング：ゲキムズ**
- **ライティング：慣れれば大丈夫**
- **リスニング：簡単**

とにかくリーディングが難しかったです。英検1級のリーディングは、英単語を知っているだけでは太刀打ちできず、幅広い分野の背景知識が求められると感じました。自然科学、歴史、地理、社会問題など、普段あまり触れない分野の文章も英語で理解しなければなりません。

TOEICが英語**を**学ぶ試験だとすれば、英検1級は英語**で**学ぶ試験だ、という違いを感じました。

一方で、ライティングは決まった構成に沿って主張を論理的に書ければ、十分に対応できそうな印象です。つまり、慣れが命です。

リスニングは、試験中は比較的簡単に感じました。ところが、実際の成績は予想ほどよくありませんでした（詳しくは後述）。

### 一次試験の結果

一次試験は合格でした！

| 項目               | CSEスコア       |
| ------------------ | --------------- |
| Reading            | 668 / 850       |
| Listening          | 701 / 850       |
| Writing            | 688 / 850       |
| **合計**           | **2057 / 2550** |
| 合格基準           | 2028            |
| **合格基準との差** | **＋29**        |

ギリギリではありますが、なんとか合格できました。

分野別の素点は以下のとおりです。

| 項目      | 素点  | 得点率 | CEFR |
| --------- | ----- | ------ | ---- |
| Reading   | 25/35 | 71%    | B2   |
| Listening | 21/27 | 78%    | C1   |
| Writing   | 47/64 | 73%    | C1   |

試験中の手応えと実際の結果を比べてみると、なかなか興味深いです。

簡単だと感じていたリスニングは、実際には6問も落としていました。振り返ってみると、ミスは前半に集中していて、後半は全問正解。相対的に長い後半パートの印象に、体感が引っ張られていたようです。CSEスコアこそ3技能のなかで最も高いものの、自分が思っていたほどの出来ではありませんでした。

一方、苦戦を覚悟していたライティングは、思った以上に健闘してくれました。

結果的には、3技能がそれぞれ少しずつスコアを積み上げて、合格ラインを越えてくれた形です。

## 二次試験体験記

一次試験に合格したので、2026年11月8日に二次試験を受験しました。

### 会場選びと当日の流れ

東京の二次試験会場は、「千代田」「新宿・豊島」「世田谷」の3地域から希望を選べました。

正直なところ東京の地理に疎く、私の居住地（つくば市）からどこが一番近いのかもわからないまま、なんとなく千代田を選びました。結果的には、こちらが最寄りだったようです。

会場は神田外語学院本館でした。

当日は集合時刻の約1時間前に到着しました。私は7番目で、はじめに9人が呼ばれて、それぞれの教室に誘導を受けました。なのでトップバッターで面接を受けられました。

普通に到着しても、トータルの所要時間は変わらないのかもしれません。それでも、会場内で順番を待つより、会場の外で時間をつぶしているほうが圧倒的に緊張せずに済むので、早めの到着は正解だったと思っています。

### 面接の感想

英検1級の二次試験では、1分間の準備時間のあと2分間のスピーチを行い、その後に面接官との質疑応答が続きます。

自分の意見を英語で説明し、面接官と議論すること自体は、純粋に楽しめました。

ショートスピーチでは理由を2つ挙げられたうえに、ちょうど2分で話し終えられたので、試験直後はそれなりに手応えを感じていました。

### 二次試験の結果

11月17日に二次試験の結果が発表されました。

**結果は不合格でした！**

| 項目               | CSEスコア |
| ------------------ | --------- |
| Speaking           | 596 / 850 |
| 合格基準           | 602       |
| **合格基準との差** | **−6**    |

惜しかった！

分野別の得点は以下のとおりです。

| 項目                   | 得点      |
| ---------------------- | --------- |
| Short Speech           | 5/10      |
| Interaction            | 8/10      |
| Grammar and Vocabulary | 6/10      |
| Pronunciation          | 6/10      |
| **合計**               | **25/40** |

注目すべきは、Interactionが8点だった一方で、Short Speechが5点にとどまったことです。

Short Speechの低さには心当たりがあります。質疑応答で、面接官から「XXXについてあなたはどう思いますか？」と具体的な事例について質問されたのですが、私のスピーチではその具体例にまったく触れていませんでした。

自分では理由を2つ説明したつもりでしたが、それだけでは不十分で、具体例のレベルまで落とし込む必要があったのだと、質疑応答の最中に気づきました。

また、Grammar and VocabularyとPronunciationはどちらも6点でした。こちらは素直に力不足で、まだまだ改善の余地があります。

## 総括：英検1級は英語力だけでなく教養が問われる

一次試験と二次試験を通じて最も強く感じたのは、**英検1級では英語力だけでなく、幅広い教養が問われる**ということです。

リーディングでは、さまざまな学問分野の文章を理解する必要があります。ライティングやスピーキングでは、社会問題について自分の立場を明確にし、根拠を示しながら論理的に説明しなければなりません。

私は科学技術や医療の話題には比較的なじみがあるものの、歴史、政治、経済、国際関係といった専門外の分野については、知識が十分とはいえません。そもそも日本語であっても、背景知識がなければ説得力のある意見を述べるのは難しいはずです。

今後は英語の勉強と並行して、社会問題について幅広く学んでいきたいと考えています。

### 次回に向けた学習方針

一次試験に合格したので、次回は一次試験免除で二次試験のみを受験します。受験予定日は**2027年2月28日**です。

重点的に改善したいのは、やはりShort Speechです。

ChatGPTの音声会話機能を使って、1分間で構成を考え、2分間で主張を説明する練習を繰り返す予定です。あわせて、[SDGsレポート](https://unstats.un.org/sdgs/report/2026)や[国勢調査](https://www.stat.go.jp/data/kokusei/2025/kekka.html)のデータにも目を通し、具体例まで落とし込んで話せるレベルを目指します。

## おわりに

今回の英検1級初挑戦は、一次試験はギリギリ合格、二次試験はあと6点届かず不合格という結果でした。

悔しさはありますが、改善すべき点がはっきりしたのは大きな収穫です。

また、受験を通じて、英語そのものだけでなく、社会のさまざまな問題について学ぶ楽しさも感じました。英検1級の勉強は、単なる語学学習にとどまらず、自分の視野を広げるきっかけにもなりそうです。

2月の再挑戦に向けて、引き続き頑張ります！
